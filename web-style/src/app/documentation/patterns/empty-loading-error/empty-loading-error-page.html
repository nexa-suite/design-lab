STATE TAXONOMY

Meaning determines treatment, not a generic template

EmptyFirst-use, no-results and filtered empty are different causes.
In progressLoading and determinate progress preserve surrounding context.
RecoveryUnavailable, permission, conflict and retryable error name the next safe action.
Non-retryableSome failures need a new decision or owner; retry is not presented as a false recovery.
TerminalSuccess and cancelled stop until an explicit next action occurs.

ACCESSIBLE FALLBACK

State meaning is available through text, icon and status

Color supports the message; it never carries the state alone. Status is exposed through a live region and the action remains a native control.
