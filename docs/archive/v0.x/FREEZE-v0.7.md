# Nexa Design Lab v0.7 — Freeze

## Frozen for this candidate

- Light appearance is canonical.
- Sidebar width behavior, grouping, spacing, PrimeIcons, active row, pale blue selected surface, blue leading cue, disclosure and mobile drawer remain unchanged.
- Text Field border, radius, padding, focus geometry, typography relationship and label relationship remain unchanged.
- Plus Jakarta Sans, Inter and JetBrains/system mono remain the candidate families.
- Blue identity, neutral hierarchy, semantic support families and white structural surfaces remain the primary foundation.
- State evidence is explicit and deterministic; no autoplay.

## Retired from the active runtime

- screen-library navigation;
- screen-library routes and shells;
- screen-library-only components and dead data imports;
- visual-provenance metadata tied to external comparison sources.

The retired implementation is preserved by Git history, not by a hidden active route or archive folder. Authentication survives only as a composition specimen under `Patterns / Authentication`.

## Deferred

- dark mode and additional appearance themes;
- Figma library publication;
- production component package extraction;
- final accessibility certification;
- production application adoption;
- release tag and public publication.

## Review rule

Frozen means the current human direction is protected from casual visual drift. It does not mean production-ready or finally approved by CodeX. Any change to a frozen direction needs a new human decision.
