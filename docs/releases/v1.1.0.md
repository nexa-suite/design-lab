# Nexa Design Lab v1.1.0

## Scope

- **Triad Monorepo Architecture**: Consolidated the Design Lab into three specialized environments:
  * `web-style` (Port 4200): Angular 22 component library `nexa-ui` and desktop design guidelines.
  * `mobile-style` (Port 4201): Astro + Material 3 Android Jetpack Compose and Flutter specifications with multi-device hardware simulator.
  * `website-style` (Port 4321): Astro + Nexafy Living Geometry Engine, interactive drag-and-drop puzzle workbench, and SOTD forensic landing suite.
- **Centralized Shared Resources (`shared/`)**:
  * `shared/tokens/`: Canonical Design Tokens in W3C DTCG format (`primitive`, `semantic`, `component`, `data-visualization`, `icons`).
  * `shared/brand/`: Canonical vector SVG logos and wordmarks (`logo-nexa.svg`, `Documento.svg`).
  * `shared/README.md`: Centralized documentation on cross-package token and asset synchronization.
- **Mobile Guidelines & Simulator Overhaul**:
  * 5 hardware form factors: Galaxy S24 (390dp), S24 Ultra (412dp), Zebra TC58 (412dp), Galaxy Tab Active 8" (600dp), and Galaxy Tab S9 11" (800dp).
  * Container-query adaptive Kanban (`@container`): Single full-width active column with quick tab switching on phones, expanding to 4 spacious side-by-side columns on tablets.
  * Permanently active M3 TopAppBar and BottomNav (Rutas, Despacho, Picking, Checklist).
  * Canonical B2B cold-chain operations screen as default view.
  * Dual-mode showcase toggle between Live Interactive Simulator and 5-Device Side-by-Side Gallery.
- **Living Geometry Engine (Nexafy)**:
  * Interactive canvas with pure solid brand colorimetry (`#082846` deep blue, `#38c8ff` accent, pure white `#ffffff` canvas).
  * Draggable modular puzzle blocks with collision avoidance and live coordinate inspection.
  * 28px thick vascular contour fillets and 24px dotted architectural grid.
- **Unified Gateway & Container Orchestration**:
  * Nginx reverse-proxy hub on port 8090 routing `/web/`, `/mobile/`, and `/website/`.
  * Container cache-invalidation headers (`no-store, no-cache, must-revalidate`).
  * Root workspace cleanup removing obsolete untracked build artifacts.

## Boundary

This release represents executable design evidence and interactive design-system authority across Web, Mobile, and Website. It remains isolated to the `design-lab` monorepo without altering production backend APIs or operational databases.

## Source of truth

Design Lab `main` at the `v1.1.0` release is the current executable baseline for design guidelines, tokens, and multi-device UI specifications. Blueprint remains normative for domain architecture and system-wide governance.
