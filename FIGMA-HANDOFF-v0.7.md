# Nexa Design Lab v0.7 — Figma Handoff

## Handoff status

Prepared mapping only. No Figma file, library or component publication is performed by v0.7.

## Mapping contract

Each candidate should map to a Figma component set with:

- semantic name and purpose;
- variant and size properties;
- state properties;
- token references for primitive, semantic and component roles;
- accessibility annotations for name, focus, target, contrast and non-color cues;
- open questions and human owner.

## Foundation mapping

| Angular evidence | Figma preparation |
| --- | --- |
| Blue and neutral ramps | primitive variables with usage notes |
| Semantic color families | role variables and approved pair annotations |
| Typography matrix | text styles with family, size, weight, leading and tracking |
| Spacing and layout | Auto Layout padding, gap, min/max and reflow notes |
| Shape and surfaces | radius, border, elevation and plane roles |
| Motion inspector | trigger, property, duration, easing and reduced fallback |

## Component mapping

Buttons, Text Fields, Toggle, Segmented Control, Cards/Surfaces, Status, Progress, Numeric Stepper and Slider have enough rendered evidence to prepare a first library review. Choice controls, overlays, tables and navigation still need human component-set decisions before publication.

## Implementation evidence

Angular specimens are the implementation counterpart, not an automatic source of design truth. Human designers own visual approval, variable naming changes and Figma publication. Production repositories remain a separate approval boundary.
