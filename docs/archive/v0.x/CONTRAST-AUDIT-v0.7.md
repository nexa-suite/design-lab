# Nexa Design Lab v0.7 — Contrast Audit

## Method

The lab evaluates actual candidate foreground and background token values through `src/app/shared/contrast.ts`. It supports hex, RGB and OKLCH candidates, converts them to relative luminance and computes the WCAG contrast ratio:

```text
(L lighter + 0.05) / (L darker + 0.05)
```

Thresholds:

- normal text: `4.5:1`;
- large text: `3:1`;
- essential non-text UI and focus indicators: `3:1`.

Ratios shown in the page are generated by `evaluateContrast`; no ratio is hand-entered in the UI. The deterministic gate fails a pair when its measured ratio is below the required threshold.

## Mode behavior

Standard and Increased Contrast use the same semantic contracts. Increased Contrast strengthens the mode-level text, border and focus aliases. It is an evaluation mode, not a second appearance or dark theme.
