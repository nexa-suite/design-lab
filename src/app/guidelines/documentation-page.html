NEXA PRINCIPLES

Make the next correct action easy to see

01

Operational before ornamental

Every surface earns its space by helping a user review, choose, validate, move or recover.

02

Domain language is interface language

Sales, Buyer Portal, request, order, dispatch and document are not interchangeable labels.

03

State must be truthful

Color, text, icon and affordance agree. A visual loading state never invents business completion.

04

Quiet hierarchy, deliberate density

White work surfaces, structural borders and spacing create scan paths without card soup.

05

Accessible by construction

Semantics, keyboard, focus, contrast, reflow and reduced motion belong in the component contract.

DECISION TEST

Would a designer, engineer and QA person reach the same conclusion?

If not, the rule is not documented deeply enough. Add anatomy, states, behavior, provenance and a real Nexa use case before calling it reusable.
