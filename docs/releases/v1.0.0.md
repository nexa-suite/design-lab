# Nexa Design Lab v1.0.0

## Scope

- Angular `nexa-ui` library boundary with explicit public exports.
- Frozen Nexa visual direction, token layers, typography, iconography and component contracts.
- Documentation specimens, interaction-state evidence, accessibility evaluation modes and responsive validation.
- Architecture, token, contrast, public API, package and browser gates.

## Boundary

This release is executable design evidence. It does not implement production applications, API integration, domain behavior, final product workflows or accessibility certification.

## Source of truth

Design Lab `main` at the `v1.0.0` release is the executable baseline. Blueprint remains normative for design-system governance and adoption guidance.
