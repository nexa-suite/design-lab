04 / STATES & ACCESSIBILITY

Predictable under pressure

Controls must remain understandable when the workflow is dense or the viewport is small.

Interaction states

  • Rest, hover, focus-visible, pressed, disabled and error are explicit.
  • Focus uses a blue ring with enough contrast against white surfaces.
  • Loading labels preserve the action name; no ambiguous spinner-only control.

Responsive contract

  • 320px: one column and full-width actions.
  • 700px: mobile menu opens an accessible drawer.
  • 980px: two-column KPI and panel layout.
  • 1440px: 284px shell with 12-column flow grid.

Angular implementation

  • Standalone components with OnPush change detection.
  • Signals for local interactive state and outputs for user actions.
  • Built-in control flow with stable tracking; no duplicated click logic.
  • Tokens are global; component styles consume semantic variables.
